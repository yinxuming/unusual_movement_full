# 自选股功能与左侧菜单改版说明

> 版本：v19 ｜ 日期：2026-08-30 ｜ 状态：已完成并通过测试

## 一、改版背景

原首页为单页异动监控（顶部标题+数据表格+设置弹窗）。本次改版为**左侧菜单栏三页布局**，并新增自选股监控能力。

## 二、页面结构

```
首页
├── 左侧菜单栏（sidebar）
│   ├── 菜单1：市场行情（原有异动监控功能，入口不变）
│   ├── 菜单2：自选（新增）
│   └── 菜单3：设置（原顶部设置弹窗迁入，改为常驻页面）
└── 主内容区（三页切换）
    ├── page-market：市场行情页（原表格/统计/日期选择/刷新）
    ├── page-watchlist：自选页
    │   ├── 二级菜单：异动风险（默认）｜ 普通浏览
    │   ├── 搜索框：按名称/代码模糊搜索添加股票（全A股含北交所）
    │   └── 操作按钮：导入CSV ｜ 导出CSV ｜ 刷新
    └── page-settings：设置页（监控数量/提前天数/自动刷新/请求间隔/代理配置）
```

### tab记忆机制
- 左侧一级菜单状态持久化：localStorage key `unusual_active_tab`，进入首页自动恢复最后一次选中的tab
- 自选页二级菜单状态持久化：localStorage key `unusual_wl_subtab`
- 自选页数据**懒加载**：首次切到自选tab时才拉取数据（main.js `switchTab` → `Watchlist.onTabActivated()`），避免页面初始化时无效请求

## 三、自选股数据模型

localStorage key：`unusual_watchlist`，结构：

```json
[{ "code": "000017", "market": 0, "name": "深中华A", "note": "备注", "addedAt": 1730000000000 }]
```

- `market`：东方财富市场编号（0=深/北，1=沪），secid = `market + '.' + code`
- CRUD操作：`Watchlist.addStock / removeStock / updateNote / getList`
- 移除入口：异动风险视图"操作"列、普通浏览视图"操作"列（均有confirm确认）

## 四、CSV导入导出

### 导入（js/watchlist.js）
- 编码自动识别：先UTF-8严格解码，失败回退GBK（同花顺导出为GBK）——`decodeCSVBuffer`
- 代码格式兼容：`SZ000017` / `SH600371` / `BJ832566` / `000017` / `600371` / `000017.SZ`——`normalizeCodeField`
- 首行为表头（含"代码"/"code"字样）自动跳过；代码去重；无效行计入failed并提示
- 已存在的股票跳过（保留原有备注），导入完成弹窗提示新增/跳过/失败数量

### 导出
- UTF-8带BOM + `\r\n`换行（Excel直接打开不乱码）
- 列：`名称,代码,备注`，代码格式 `SZ000017`，备注含逗号时按CSV规则加引号转义
- 文件名：`自选数据_YYYYMMDD.csv`

## 五、自选页两个视图

### 视图1：异动风险（默认）
复用市场行情页异动计算管线（`UnusualCalculator.analyzeStocks`，仅显示有100/200异动风险的自选股）：
交易日定位 → `batchGetKline`（limit=40）→ `getBenchmarkIndices` → 计算渲染。

- 表格列与市场行情页一致 + 操作列（移除）
- 统计栏：100/200异动风险数 + 自选总数
- 强制刷新仅清K线缓存（`clearKlineCache`），不影响市场行情页结果缓存

### 视图2：普通浏览
数据源与计算：

| 列 | 数据来源/算法 |
|---|---|
| 代码/名称 | 自选数据（名称以实时行情为准） |
| 流通市值/总市值 | ulist.np `f21`/`f20` |
| 涨幅 | ulist.np `f3` |
| 竞价涨幅 | (今开f17 - 昨收f18) / 昨收 |
| 换手率/量比 | ulist.np `f8`/`f10` |
| 主力净额/成交额 | ulist.np `f62`/`f6` |
| 连涨天数 | K线从最新往前连续 `changePercent>0` 计数 |
| 10日/30日涨停数 | 近N根K线 `changePercent >= 涨停幅度-0.2%` 计数（涨停幅度按板块：主板10%/创业科创20%/北证30%） |
| 涨停时间 | 东财涨停池 `fbt`（HHMMSS→HH:MM） |
| 涨停原因 | 同花顺涨停原因接口（失败降级显示`--`） |
| 前日/昨日 | K线倒数第3/第2根的 `changePercent` |
| 近2~近30日 | 最新收盘 / N根前收盘 - 1 |
| 今年来 | 最新收盘 / 今年首根K线开盘 - 1（近似去年末收盘） |
| 备注 | 自选存储note，点击单元格prompt编辑 |
| 操作 | 移除（confirm确认） |

- K线 limit=260（覆盖今年来涨幅计算），K线缓存带limit检查（不足自动重拉）
- 宽表前两列（代码/名称）sticky固定，横向滚动保持可见

## 六、新增/修改的接口（js/api.js）

| 函数 | 说明 |
|---|---|
| `getQuoteBatch(secids)` | 批量实时行情（ulist.np，每批50个） |
| `getZTPool(dateStr)` | 指定日期涨停池（push2ex，当日缓存） |
| `getTHSZTReason(dateStr)` | 同花顺涨停原因（失败降级空Map） |
| `getAllStockList()` | 全A股列表（搜索用，含北交所，当日缓存） |
| `clearKlineCache()` | 仅清K线缓存（自选强制刷新用） |
| `batchGetKline(..., limit)` | 新增第4参数limit（浏览视图260） |

## 七、渲染器工厂化改造（js/renderer.js）

- `Renderer.createTableRenderer(ids, options)` 工厂函数创建独立渲染实例，市场行情页与自选页互不干扰
- 默认导出市场行情页实例（旧接口 `Renderer.renderTable` 等不变，main.js无感兼容）
- `options.onRemove` 存在时行尾自动追加"操作"列（移除按钮）
- 表头T+N日期更新限定在实例自己的表格内（修复原 `document.querySelector` 全局查找的隐患）

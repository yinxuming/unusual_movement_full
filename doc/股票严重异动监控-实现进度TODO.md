### 1. 核心功能实现
- [x] 异动规则：10天涨幅100%，30天涨幅200%，适用于全A股（主板、创业板、科创板、北证）
- [x] 参考示例：doc\参考示例\20260608_10天100%30天200%异常波动.jpg
- [x] 同花顺标准数据：doc\参考示例\同花顺严重异动.md（识别导出markdown，作为计算结果对照标准）
- [x] 监控A股股票TOP涨幅接近异动情况
- [x] 异动监控提前量：默认5天可配置（T+0 ~ T+4）
- [x] 异动监控结果展示：股票代码、名称、最新涨幅、异动类型标签、偏离值、是否触发、当日及T+1~T+4触发涨幅限制
- [x] 异动类型二选一：每只股票只显示最接近触发的那种异动（100异动或200异动）
- [x] 按紧急程度排序（当日触发值从小到大，已触发排最后）
- [x] 偏离值列：显示趋势天数和累计涨幅（如"9日偏离值:83.34%"，与同花顺格式对齐）
- [x] 是否触发列：标记"已触发"或"未触发"（红色/灰色标签）
- [x] 偏离值计算修正（与同花顺/交易所官方规则一致）：
  - 偏离值 = 个股区间涨幅 - 对应基准指数区间涨幅
  - 区间涨幅 = (当前收盘价 / 区间最低收盘价 - 1)，取窗口内最低点为基准
  - 基准指数映射：沪市主板→上证A股指数(1.000002)，深市主板→深证A指(0.399107)，创业板→创业板综指(0.399102)，科创板→科创50(1.000688)
  - 触发值公式：x = (1 + threshold + indexGain) / (1 + stockGain) - 1（个股还需涨幅百分比）
  - 获取基准指数K线数据，用于偏离值计算
- [x] 可触发性过滤：只有T+0~T+N中至少一天可触发的才展示
  - T+0日：触发值 <= 当日涨停幅度（主板10%、创业板/科创板20%、北证30%）
  - T+N日：触发值 <= (1+涨停幅度)^(N+1) - 1（连续涨停最大涨幅）
  - 不可触发的T+N值显示为灰色删除线，hover提示"超过N天涨停限制，不可能触发"

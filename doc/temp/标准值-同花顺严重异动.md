## 字段说明

| 字段 | 说明 |
|------|------|
| 日期 | 数据日期（交易日） |
| 代码 | 股票代码 |
| 名称 | 股票名称 |
| 当日涨幅 | 当日收盘涨跌幅 |
| 严重异动规则触发条件 | 当日收盘需达到的涨幅才触发异动 |
| 规则是否触发 | 是否已触发严重异动 |
| 异动偏离值 | 当前偏离阈值多少（如"9日偏离值:83.34%"表示近9天已涨83.34%） |
| 严重异动规则 | 连续10个交易日内=100%异动；连续30个交易日内=200%异动 |

## 关键规律

1. **100异动（连续10个交易日）**：偏离值接近100%，触发条件为剩余所需涨幅
2. **200异动（连续30个交易日）**：偏离值接近200%，触发条件为剩余所需涨幅
3. **已触发案例**：中巨芯(688549)在06-11当日+19.96%后触发，偏离值114.48%（超过100%）
4. **筛选标准**：只有触发条件<=涨停幅度*N天的才有实际意义（如主板10%/天、创业板20%/天、北证30%/天）
